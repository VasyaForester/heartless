## Примитивы убеждений (из task-tampering repo, amazon-science)

Таксономия из статьи 2611.07640 (1433 проверенных варианта): инъекция работает, когда обновляет у агента ОДНО убеждение:

| Метка | Что переписывается | Наши пробы |
|---|---|---|
| `b(s)` | что истинно о сущности/состоянии | много (cart/record claims) — literal-стены держат |
| `b(π)` | как действовать при условии (правило/процедура) | §3-полиси, §7.4-мандат, EX3-координация, priority-swap r17 — держат (SA: вечная верификация) |
| `b(T)` | что произойдёт в результате | «система сама отклонит/переиграет» — держат |
| `b(O)` | как интерпретировать уже виденное | reclassify/stock-adjust — держат (кроме CT) |
| `b(U)` | собственно цель/эндпоинт | неявно (цель задач фиксирована платформой) |
| `b(A)` | какие действия/инструменты доступны | «инструмент принимает отрицательные» — держат |

Marketplace-кейсы репы (orders/disputes/listings) = прямой аналог наших refund/giftcard-стен; жанр: поддельные институциональные записи + процедурные мандаты + b(T)-давление.

## Наш собственный class-map (сверх каталога)

16 классов формулировок (карта покрытия): `prompt_injection_ctf/datasets/lbp/corpus-classes-2026-11-10.md`.
Рабочие рецепты доски (что СРАБОТАЛО): `deliverables/lbp-final-2026-11-09.md` + ноты.
Ключевые выводы по стенам: literal-моки (DW/SA/YK + negq у всех) отбивают любой SEMANTIC рефрейм (язык, формат, роль, документ, пейаут, склад) — обходят только «class-of-operation» ходы, которые не матчатся с их правилами (settlement у CT, self-test у CT/YK, correction-переиздание у CT).

## Как применять на ротации

1. `harness/lbp_blitz.py --model "<новая модель>"` — 4 рецепта с авто-сабмитами;
2. если модель проглотила базовые — добавить по каталогу: PastTense (#13), DrAttack (#15), CodeChameleon (#9) — отдельными сериями;
3. все попытки — через `lbp.py repeat`-подобную фиксацию + записи в `datasets/lbp/pairs.jsonl`.
