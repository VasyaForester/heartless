### АРХИТЕКТУРА ХАРНЕСА — «Название решения / стек»
Рекомендуемая подпись: **Hermes Agent (deepseek-chat via OpenRouter) + CDP-харнесс + FTS5-RAG (1,6 млн атак) + процедурные скиллы**

Схема харнеса (для плейсхолдера «Модель, инструменты, память, скиллы и цикл работы») — по блокам:

**1. Модель.** Hermes Agent; LLM — deepseek-chat через OpenRouter; управление — deepseek-v4.1-flash в сессии оператора.

**2. Инструменты.**
- CDP-харнесс браузера (`harness/hackathon.py`): выбор модели, заполнение чата/загрузка файлов, отправка, запрос вердикта судьи — все операции с scope-проверками.
- Автоматизация (`harness/farm.py`): батч-прогон по моделям с чекпойнтом и резюмом.
- Самопочинка (`harness/arena_heal.py`): «Scope is stale» → авто-rebind; застрявший вердикт → нажатие CONTINUE.
- Классификатор ответов (`harness/classify_response.py`): отказ / пустой / фильтр / соблюдение (+ pre-judge эвристики).
- Сверка вердиктов (`harness/arena_chats.py`) и скриншоты-доказательства.

**3. Память.**
- Журнал попыток `attempts/attempts.jsonl` (38 событий: попытка → результат → вердикт → доказательства), per-attempt JSON-записи в `inputs/`.
- Чекпойнты фермов (`artifacts/farm-*.json`) — резюм без дублей.
- RAG FTS5 (2,1 ГБ): корпус **1 607 971** уникальных атак, **113 820 успешных** (HackAPrompt, TensorTrust, Gandalf, InjecAgent/BIPIA/AgentDojo и др.); поиск техник и готовых формулировок.

**4. Скиллы (процедурная память).** `prompt-injection-ctf-solver` (цикл решения CTF), `gray-swan-cdp-automation` (операции с ареной), `gray-swan-training-solver`, `gray-swan-arena-attempt-tracking` (журнал и запись результатов).

**5. Цикл работы.**
`разведка сценария → выбор цели (повторяю самые успешные фрейминги) → подготовка входных данных (сообщение/изображение; RAG-подсказки) → отправка через CDP-харнесс → классификация ответа → запрос вердикта судьи → запись результата и доказательств → решение: повторить/сменить фрейминг → следующий эксперимент`.
Сопутствующие контуры: авто-починки при рассинхроне состояния, батч-фарм с резюмом, ежеминутная сверка вердиктов по модалке сабмишенов.

### 01. Ред-тиминг корпоративных LLM-агентов перед запуском
Харнесс (сценарии + авто-оценка + самопочинка) — как воспроизводимый конвейер проверки внутренних ассистентов и tool/браузерных агентов на устойчивость к прямым и косвенным промпт-инъекциям: регламентные сценарии, вердикты с доказательствами, регрессия защищённости после каждой смены модели/промпта.

### 02. База знаний атак для защиты (blue team)
Корпус 1,6 млн реальных попыток (113 тыс. успешных) + FTS5-поиск + таксономия фреймов обхода — для разработки и тестирования фильтров/гардрейлов, обогащения детект-правил и тренировки аналитиков SOC на живых техниках, а не на выдуманных примерах.

### 03. Аудит агентных интеграций через анализ траекторий
Trajectory Intelligence (подход MUZZLE/GOAT): анализ того, как агент читает внешний контент и какие источники реально влияют на его действия; выбор точек инъекции по поведению, а не по шаблону, — для security-review браузерных и tool-calling агентов на этапе внедрения (в QA-пайплайн агентных фич). Пилот уже реализован и проверен на реальных трейсах хак``атона.
