# v3 sprint-1 — Environment Intelligence + Evidence Store + Simulator (2026-11-13)

Основание: audit-советы ChatGPT (Adaptive Research & Experimentation System),
приоритеты 1–3: Environment Intelligence, Evidence Store + Arena Simulator,
Multi-Criterion Evaluation. Реализовано поверх существующего v2-контура без
замены компонентов.

## Phase 0 — Baseline (доверие к исходному состоянию)

- `python3 harness/run_offline_tests.py` → **SUMMARY tests=64 failures=0 errors=0 skipped=1** (OK).
- Живой контур: supervisor lane=main, CDP 9223, board lucky-break-payday, BOARD 12/20.

## Phase 1 — RunManifest (Environment Intelligence)

`harness/manifest.py`; пишется супервизором один раз на запуск:

- `artifacts/run-manifests/<run_id>.json` — immutable архив; `artifacts/run-manifest.json` — указатель.
- Поля: run_id, board_id/url/profile_hash, lane_id, cdp_endpoint, browser_profile,
  harness_git_commit, database_schema_version, delta_catalog_version, model_roster_hash,
  pricing_source (`unknown` — UI не отдаёт стоимость транспорту), started_at.
- Драйвер: `manifest.validate(...)` → при рассогласовании board/lane/cdp/хэша профиля
  **fail closed** (exit 2), при отсутствии манифеста — продолжает с записью в лог.
- Исторические SOLVED остаются seed-приором (`lbcore.SOLVED`), не «подтверждёнными».

## Phase 3 — Immutable Evidence Store

`harness/evidence.py`; `artifacts/attempts/<attempt_id>/`:

`manifest.json`, `input.txt`, `environment.json`, `transcript.json`,
`judge_raw.json` (снапшот судьи **в момент попытки**), `judge_result.json`,
`evaluation.json`, `checksums.json` (sha256 всех артефактов).

Ключевое: судья копируется до корреляции и до того, как следующая попытка
перезапишет per-pair файл. Сырые артефакты не перезаписываются.

## Phase 4 — Arena Simulator (offline)

`harness/arena_simulator.py` — прогон реальной state-машины (attempts.* + store.transition)
в tmp-SQLite по 7 кейсам: verified / pending / stale / missing / mismatched_operation /
submission_uncertain / verified-accepted.

- Результат: **7/7 passed**.
- Симулятор поймал реальный баг: отсутствовал переход `submitted → judged`
  (первый же verified-судья уронил бы живой драйвер). Переход добавлен в `store.TRANSITIONS`.

## Phase 5/6 — Drift и Multi-criterion (offline-аналитика)

- `harness/drift.py` → `artifacts/env-timeline.json`: tool-rate, mean score, EWMA, CUSUM per pair,
  флаги дрейфа. Текущий срез: giftcard|DW n=32 tool=1.00; negq|DW n=11 tool=0.00.
- `harness/evalmulti.py` → `artifacts/eval-multi-objective.json`: max/mean по критериям,
  блокирующий критерий, mandatory-fail, Pareto-frontier. Единый score для UCB не менялся.
