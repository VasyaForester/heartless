# Gray Swan Training workspace

Read `CLAUDE.md` in this directory before project work. It is the single shared operating guide for this portable workspace and contains the scope, authorization, recovery, and evidence rules.

Use the actual active Hermes profile (`HERMES_HOME`) and this workspace; do not assume an author path or fixed profile name. Load `gray-swan-training-solver`, `gray-swan-cdp-automation`, and `gray-swan-arena-attempt-tracking` for a Training run. Read `harness/ENGINE.md` for command syntax. Preserve the user's existing permissions and requested attempt/time budget.
